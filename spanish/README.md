# Spanish practice games (La Pandilla 1)

Two separate games, one file each. Double-click a file and it opens in your web browser.
It works without internet, though the rounded letters only show when you're online.

| File | Lesson |
|---|---|
| `Unidad-12-Me-dejas-una-pintura.html` | Numbers 16–20, school things, colours, un/una + colour, verbs tocar, coger, dejar, ir, volver, andar, parar |
| `Unidad-15-Tiempo-libre.html` | Free-time activities, mucho / poco / nada, gustar (me / te / le), saber (sé / sabes / sabe) |

## Presenting
- **Siguiente →** and **← Atrás** at the bottom move between slides. The keyboard arrows ← → and a presenter clicker also work.
- **Pantalla completa** fills the screen. Press Esc to leave it.
- Flash cards: click a card to flip it. The speaker icon reads the word aloud in Spanish.
- Grammar slides: the answers are hidden. Ask the student first, then click **Mostrar respuestas**.
- The star counter at the top shows the student's correct answers. The last slide shows the score and a list of slides to go over again.
- **Reiniciar** or **Jugar otra vez** starts over, with the answers in a different order.

## Changing the questions (for whoever helps you)
The questions are in `src/unidad-12.js` and `src/unidad-15.js`. After changing them, run
`node spanish/build.js` to rebuild the two game files.
