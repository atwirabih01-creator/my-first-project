## 2. What the project is

**Cold Read**: a free, dark, serious detective game in the browser (phone and computer, English)
that trains real skills: noticing details, connecting clues, reading behaviour. Inspired by the
style of The Mentalist, fully original. Approved plan: `docs/Cold-Read-Game-Plan.pdf`. Creative
brief for agents: `game/BRIEF.md`.

Key decisions (all approved by the owner):

| Topic | Decision |
| --- | --- |
| Player | Julian Marsh, ex-TV psychic, consults for Port Halden PD Major Crimes |
| Helpers | DS Lena Cruz (partner, gives hints), Theo Park (tech, records by phone) |
| City | Port Halden (invented): Old Town, The Docks, Hillcrest, Eastgate, Financial Quarter |
| Tone / rating | Dark and serious; victim shown but no gore; 16+ |
| Look | **Changed 2026-10-06: realistic photos** for people and places (was illustrated) |
| Solving | Build the case: killer + motive + method + 3 proofs (`proofsNeeded: 3`) |
| Time | In-game clock; results arrive as you play; "Wait 30 min" / "Wait until morning" at HQ |
| Hints | Earned, point where to look, never the answer |
| Wrong case | Wrong person charged, story consequence; reopen = same killer, changed trail (some cases: different killer) |
| Learning | Debrief after each case: found/missed, real technique, real-life tip |
| Structure | 1 case per level, 10 per chapter, 3–4 connected per chapter; aim 10 chapters, launch with Chapter 1 |
| Platform | Browser first (free hosting), login later; app stores later |
| Budget | Close to zero |
| Case writing | The team writes; owner approves (pilot skipped the summary to avoid spoilers) |
| Instagram | Plan only (weekly hints); owner creates and posts |

Roadmap: plan (done) → **pilot case (now)** → Chapter 1 (10 cases + login) → launch + Instagram →
new chapters.

## 6. Methods that work (keep using)

- **Environment:** Network access set to **Full** (owner, 2026-10-06), so external sites work.
- **Canva full-size export:** thumbnails are signed and can't be resized. Put the media id on a
  page of the export design "Blank black game artwork canvas" (DAHXOFPgYVY): `read-design`
  with `open_transaction` → `add_page` sized to the image → `insert_fill` at 0,0 full size →
  commit → `export-design` jpg with page numbers → curl the URLs into `game/images/`. Canva
  blocks visible bodies: show the body under a forensic sheet.
- **Adding a photo:** save as `game/images/<art key>.jpg` (people ~4:5; scenes 5:3, the engine
  crops to a 1000×600 box from the centre), add a line in `game/photos.js`, and for scenes
  re-place hotspot `x, y` in `case-001.js` so each sits on its object; run the validator.
- **Tests:** `node game/tools/validate-case.js`;
  `NODE_PATH=/opt/node22/lib/node_modules ONLY=smoke node game/tools/e2e-test.js`
  (`ONLY=test|smoke|real`; real takes several minutes). Chromium: `/opt/pw-browsers/chromium`.
- **Owner build:** a single-file HTML with CSS/JS inlined and photos as data URIs (script used in
  the session: read styles.css, art.js, photos.js with images base64-encoded, case-001.js,
  engine.js into one `<!doctype html>` page; escape `</script`). Send with SendUserFile.
- **Agents used so far** (same session ids won't carry over; start fresh ones): Narrative
  Designer (case content), Frontend Developer (engine), Technical Artist (SVG art), Reality
  Checker (fairness review), Evidence Collector (QA play-through).
