# Cold Read: pictures to make

How to do it (about 2 minutes per picture):

1. Open a free AI image tool, for example **Microsoft Designer** (designer.microsoft.com, "Image creator")
   or **Bing Image Creator** (bing.com/create). Sign in with a free Microsoft account.
2. Copy one description below, paste it in, and press create.
3. Pick the best result and download it.
4. Upload it in the Claude chat and say which number it is, for example "this is picture 1".

Tips: choose **landscape (wide)** for places and **portrait (tall)** for people when the tool
asks. If a picture comes out wrong (cartoonish, wrong age, text on it), just try again.
